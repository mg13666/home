# 二次元个人引导主页

一个漂亮的二次元风格个人导航主页，集成一言 API、APlayer 音乐播放器、PWA 渐进式应用支持、落叶特效等。

## 在线演示

[https://my.heheda.top](https://my.heheda.top)

## 特性

- 🎨 二次元风格响应式布局
- 💬 一言 API 随机语录
- 🎵 APlayer 音乐播放器（支持歌单）
- 🍂 落叶飘落特效
- 📱 PWA 渐进式应用支持
- 🔍 SEO 优化
- 🎯 FontAwesome 图标库
- 🌙 加载动画 & 转场效果

## 快速开始

1. Clone 仓库
2. 部署到任意静态服务器（Nginx/Apache/CDN）
3. 根据需要修改 `index.html` 中的个人信息和链接

### 自定义背景

修改 `heheda/css/main.css` 第 187-190 行 `url()` 中的图片链接。

### 自定义音乐

修改 `index.html` 中 audio 标签的 `src`，或注释掉以禁用。

## 技术栈

- HTML5 + CSS3 + JavaScript (jQuery)
- APlayer 音乐播放器
- FontAwesome 4.7
- PWA (Service Worker)
